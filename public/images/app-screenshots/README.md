# App screenshots

Drop real captures of the Metri Android app here and point `lib/app-tour.ts`
at them (`image: "/images/app-screenshots/<tab>.png"`). Until a step has an
image, the landing page renders its CSS mockup instead.

Expected files (portrait, 1080×2340 or any 9:19.5 frame, PNG):

- `home.png`
- `train.png`
- `metrics.png`
- `nutrition.png`
- `explore.png`
